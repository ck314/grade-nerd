Example 3: Connection to Neural Networks (Loss Landscape)

  • Concept: Training a neural network is essentially an optimization problem. The network tries to find the set of weights that minimizes the "Error" (or Loss). If we visualize the Error as a landscape, it looks like a valley or a bowl. The bottom of that bowl is the Vertex. Vertex form describes this "Error Bowl." The goal of the training algorithm (Gradient Descent) is to find the coordinates of the vertex (h,k)(h, k)(h,k)﻿ because that is where the error is lowest.
  • Formula: Error(w)=a(w−h)2+kError(w) = a(w - h)^2 + kError(w)=a(w−h)2+k﻿ (Where www﻿ is the weight, and we want aaa﻿ to be positive so there is a minimum).
  • Example: A single neuron's error function relative to a weight www﻿ is modeled by E=2(w−4)2+0.5E = 2(w - 4)^2 + 0.5E=2(w−4)2+0.5﻿ . What is the ideal weight for this neuron to minimize the error, and what is that minimum error?
  • Calculation:
    1. Identify the Vertex (h,k)(h, k)(h,k)﻿ :
      • h=4h = 4h=4﻿ (from (w−4)(w - 4)(w−4)﻿ )
      • k=0.5k = 0.5k=0.5﻿
    1. Check direction: a=2a = 2a=2﻿ (positive), so the parabola opens UP. The vertex is a Minimum.
  • Conclusion: To achieve the best performance (lowest error), the weight www﻿ should be set to 4. The minimum possible error for this neuron is 0.5.
