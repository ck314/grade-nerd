Feasibility Analysis - for a 5 year old

🧠 What is it? (WHAT)

Imagine a little robot inside a computer 🤖.

This robot is trying to be perfect.

Perfect means:

👉 Zero mistakes at all 🎯

The robot follows a math rule that tells it how many mistakes it makes.

Now we ask an important question:

💭 “Is it even possible for this robot to make ZERO mistakes?”

The discriminant is a math tool that helps us answer that question.

🤔 Why do we care? (WHY)

Sometimes the robot tries really hard…

But no matter what it does, perfect is impossible 😕

That’s not the robot’s fault!

The math rule itself might make perfection unreachable.

So before trying forever, we check:

👉 “Is this goal possible at all?”

The discriminant tells us:

  • ✅ Yes, it can happen
  • ⚠️ Yes, but only one special way
  • ❌ No, it can never happen

🔧 How does it work? (HOW)

The robot’s mistake rule looks like this:

“Mistakes = 2 × w × w − 4 × w + 5”

Where a is that first 2

And b is that -4 in the middle

And c is that 5 at the end

To check if zero mistakes is possible, we use a magic checker:

🪄 Discriminant = b × b − 4 × a × c

This checker gives us a number.

That number tells us the answer!

📉 A Simple Story Example

The robot asks:

“Can I ever reach ZERO mistakes?”

Math checks the rule and says:

b × b = 16

4 × a × c = 40

So we get:

16 − 40 = −24

Uh oh 😬

That number is negative.

🧠 What does that mean? (Kid Version)

If the number is:

🟢 Positive → The robot can win in two ways

🟡 Zero → The robot can win in one tiny way

🔴 Negative → The robot can’t win at all

Since we got −24:

❌ Zero mistakes are impossible for this robot.

🧠 Big Idea (Kid Version)

The discriminant is like asking:

👉 “Is the prize even reachable?”

If the answer is no:

  • The robot isn’t broken
  • The goal isn’t bad
  • The rules need to change

So engineers change the robot’s math

And try again 💡🤖
